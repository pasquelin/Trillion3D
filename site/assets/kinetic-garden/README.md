# Geometry garden

An original procedural scene made for the learning portal. No third-party models, textures,
shaders or sample code are used. Geometry and materials are generated by
`scripts/docs/garden-source.mjs` under the repository license.

Nine parametric rings and one wave-shaped plinth contain 35,840 source triangles. An imported
directional light illuminates the materials and casts shadows; the portal controls scale its source
intensity and can disable its shadows without replacing the imported light. The native compiler
generates the manifest and geometry pages served by the example. This compact teaching scene is not
a performance benchmark or a demonstration of large-scene residency pressure.

Regenerate from the repository root with `pnpm build:native`, then `pnpm docs:scene`.
`WG_COMPILER` optionally selects a compatible compiler executable. Source generation is
deterministic; compiler timings and source provenance reflect the actual compilation run.

The live example uses the public browser SDK and its WebGPU page backend, from the portal's own
runtime bundle, built from the installed dependencies; no third-party engine code is copied into the
repository.
