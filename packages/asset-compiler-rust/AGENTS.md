# Native compiler rules

Follow the repository rules and packages/AGENTS.md principles. Keep the CLI thin. Algorithms belong in the library behind versioned strategy/stage contracts. Check cancellation at bounded work boundaries, preserve triangle/material identity, validate every persisted cache entry, and retain golden fixtures and raw before/after timing evidence. Do not claim unimplemented simplification, compression, hard memory enforcement, N-API bindings or a platform release as delivered.
