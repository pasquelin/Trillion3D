# Golden fixture — TGA driver

Seven tiny files, one per profile that the `tga` driver must read losslessly, plus a truncated
file that it must refuse by name. The golden `src/plugins/tests/tga.rs` decodes them and compares
the RGBA8 pixels **one by one** against a reference written in the clear in the test: a 4 × 2
pixel image whose eight values are known.

| file                              | image type | depth                  | origin | what it puts under watch                                     |
| --------------------------------- | ---------- | ---------------------- | ------ | ------------------------------------------------------------ |
| `vraies-couleurs-24-bas.tga`      | 2 (raw)    | 24 bits                | bottom | BGR → RGB, rows flipped, alpha filled to 255                 |
| `vraies-couleurs-32-haut.tga`     | 2 (raw)    | 32 bits                | top    | alpha kept as-is, “TRUEVISION-XFILE.” 2.0 footer             |
| `vraies-couleurs-32-rle-haut.tga` | 10 (RLE)   | 32 bits                | top    | repeated packets **and** raw packets, same pixels as the raw |
| `vraies-couleurs-32-rle-bas.tga`  | 10 (RLE)   | 32 bits                | bottom | RLE and row flip together                                    |
| `palette-8-haut.tga`              | 1 (raw)    | 8 bits, 24-bit palette | top    | palette indices resolved to the same colours                 |
| `niveaux-de-gris-8-bas.tga`       | 3 (raw)    | 8 bits                 | bottom | grey expanded to RGB, alpha 255                              |
| `tronque.tga`                     | 2 (raw)    | 24 bits                | bottom | 31 bytes out of 196,652: header recognised, decode refused   |

The three 32-bit variants and the 24-bit one carry the same image; only the 24-bit alpha is
filled, because the format has none. The golden checks this explicitly: that is the proof that
origin, compression and depth do not change a single byte of the result.

## Provenance and licence

- The six readable images are **written here**, byte by byte, from the public specification
  “Truevision TGA File Format Specification, Version 2.0”. No editor tool, no SDK.
  Author: WebGeometry corpus, 2026-09-15. Licence: **CC0-1.0**
  (<https://creativecommons.org/publicdomain/zero/1.0/>), redistributable without condition.
  Their pixels were checked by an independent decoder (Pillow 12.2.0) before being committed:
  an error in both the encoder and the decoder would not pass the double read.
- `tronque.tga` is taken as-is from `test/assets/limites/truncated-tga/truncated.tga`, also
  **CC0-1.0** (WebGeometry corpus, generated by `test/assets/tools/texture_assets.py`). The
  `test/assets/` folder is shipped off git: the file is copied here so the golden does not depend on it.

The four 256 × 256 TGAs of `test/assets/textures/tga-matrix/` (24 and 32 bits, raw and RLE, top
and bottom origins, CC0-1.0, produced by Pillow) cover the same matrix at large size. The driver was
run over them during development; they are not committed here — a quarter of a megabyte
per file for pixels that cannot be written in the clear is not a minimal fixture.
