# Unity fixtures

## `cc0-import-project`

Minimal Unity project, **CC0-1.0**, taken from the local corpus `test/assets/unity/cc0-import-project`
(generated by `test/assets/tools/unity_assets.py`, WebGeometry corpus, 15 September 2026). The repository
ignores `test/assets/`: only the files the driver needs are copied here, with their
notice, `LICENSE.txt`. The corpus editor's C# script is not taken — this driver reads only
data, and no script has a place in a fixture.

Taken as-is: `Assets/Map.unity` and its `.meta`, `Assets/Materials/{Standard,URP,HDRP}.mat`,
`Assets/Models/LODProp.fbx` (LOD 320/80/20 triangles), `Assets/Prefabs/Prop_Standard.prefab`,
`Assets/Textures/checker.tga`.

Added here, under the same CC0-1.0 licence, to cover what the corpus does not carry — the corpus
scene only places built-in cubes with a `LODGroup`:

- `Prop_Model`: a `MeshFilter` that points at the FBX by GUID, at position (1, 2, 3), rotated a
  quarter turn around Y and scaled by 2 — axis conversion and composition with the
  FBX driver are checked there in the clear; its `fileID` does not appear in the `.meta`
  name table, so the whole model is instantiated and the fact is counted;
- `Prop_SubMesh`: the same model, but a `MeshFilter` that targets `fileID` 4300002, which the `.meta`
  `internalIDToNameTable` names `Icosphere.001` — only that mesh is kept;
- `LODProp.fbx.meta` declares `globalScale: 2` and `useFileScale: 1`: the import scale applies
  to the nodes poured from the model, never to its geometry;
- a lamp on that same object, so it is counted without being rendered;
- `Prop_Cutout` and `Prop_Glass` with `Assets/Materials/{Cutout,Glass}.mat`, written here: cutout
  (Standard `_Mode: 1`, `_Cutoff: 0.25`) and transparent (URP `_Surface: 1`, alpha 0.5,
  emission, double-sided) modes;
- `Prop_Hidden`, inactive, which must produce no node;
- `Prop_Glass` carries real-project `fileID`s, beyond 2^53
  (`33000014169494082`, `23000014090315290`): read through a float they would designate an
  object that does not exist, and the object would disappear from the scene;
- two instances of `Prop_Standard.prefab`: `Prop_Copy`, moved to (-4, 0, 5), renamed, rescaled
  on y, whose LOD0 renderer material is replaced by `Glass` and whose `LOD2`
  object is disabled; `Prop_Muted`, whose LOD0 renderer is turned off. The edits this driver does not
  render — `m_StaticEditorFlags`, `m_TagString` — remain counted, property by property.

The `cc0-import-project` folder itself serves as proof for the router: it carries a scene and an FBX,
and routes to `unity` without anything being designated to it.

The golden's expected is in `cc0-import-project/expected.json`.
