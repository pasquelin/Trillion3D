# T3D-W099 — `image-uri-not-relative`

<!-- Generated from packages/sdk-node/src/messages/messages.json by scripts/message-pages.ts: edit the catalogue, then run `pnpm run generate:messages`. -->

Level: **warning**. Group: [Images](../COMPILER_ERRORS.md#images).

A texture URI is absolute or leaves the model's folder, so its texture levels are not baked.

**Cause.** An image URI with a root, `..`, `.` or a platform separator.

**What to do.** Use a URI relative to the model file, inside its folder.
