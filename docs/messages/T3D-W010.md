# T3D-W010 — `light-emitter-radius-invalid`

<!-- Generated from packages/sdk-node/src/messages/messages.json by scripts/message-pages.ts: edit the catalogue, then run `pnpm run generate:messages`. -->

Level: **warning**. Group: [Lights and OBJ/MTL materials](../COMPILER_ERRORS.md#lights-and-objmtl-materials).

A light's emitter radius is not usable, so it is omitted and the light kept.

**Cause.** A radius, declared or measured, not finite, not strictly positive, or not strictly below `range`; the field is omitted, the lamp kept

**What to do.** Give the light a positive radius smaller than its range.
