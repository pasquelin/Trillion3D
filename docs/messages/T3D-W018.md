# T3D-W018 — `material-separate-opacity-texture`

<!-- Generated from packages/sdk-node/src/messages/messages.json by scripts/message-pages.ts: edit the catalogue, then run `pnpm run generate:messages`. -->

Level: **warning**. Group: [Lights and OBJ/MTL materials](../COMPILER_ERRORS.md#lights-and-objmtl-materials).

An opacity map separate from the base colour was dropped; glTF reads opacity from the base colour's alpha only.

**Cause.** An FBX or OBJ opacity map naming another image than the base colour.

**What to do.** Put the opacity into the alpha channel of the base-colour texture.
