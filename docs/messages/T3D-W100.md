# T3D-W100 — `image-uri-outside-source`

Level: **warning**. Group: [Images](../COMPILER_ERRORS.md#images).

A texture URI resolves outside the model's folder, so its texture levels are not baked.

**Cause.** An image URI whose resolved path leaves the source folder.

**What to do.** Move the texture into the model's folder.
