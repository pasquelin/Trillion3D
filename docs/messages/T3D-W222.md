# T3D-W222 — `image-colour-description-unsupported`

<!-- Generated from packages/sdk-node/src/messages/messages.json by scripts/message-pages.ts: edit the catalogue, then run `pnpm run generate:messages`. -->

Level: **warning**. Group: [Images](../COMPILER_ERRORS.md#images).

The AVIF colour description is not supported by the decoder.

**Cause.** The AVIF colour property uses an unrecognised description type.

**What to do.** Export the image as a still sRGB AVIF with standard colour metadata, or use PNG.
