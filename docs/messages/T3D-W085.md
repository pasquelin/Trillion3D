# T3D-W085 — `psd-header-invalid`

<!-- Generated from packages/sdk-node/src/messages/messages.json by scripts/message-pages.ts: edit the catalogue, then run `pnpm run generate:messages`. -->

Level: **warning**. Group: [Images](../COMPILER_ERRORS.md#images).

A Photoshop file's header is out of range, so the texture falls back to white.

**Cause.** Photoshop header out of domain (unknown version, non-zero reserved bytes, zero or over-ceiling side, channel count out of range or below its mode's colour channels)

**What to do.** Save the file again from Photoshop, or export it as PNG.
