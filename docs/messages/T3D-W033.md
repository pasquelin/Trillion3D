# T3D-W033 — `blend-alpha-texture-unsupported`

<!-- Generated from packages/sdk-node/src/messages/messages.json by scripts/message-pages.ts: edit the catalogue, then run `pnpm run generate:messages`. -->

Level: **warning**. Group: [Blender](../COMPILER_ERRORS.md#blender).

An alpha input from another image or node was dropped; the declared alpha is kept.

**Cause.** `Alpha` from an image the base colour does not carry, or a computed node; glTF reads opacity only from the base-colour texture's alpha, so the declared factor is kept

**What to do.** Put the alpha into the base-colour image's alpha channel.
