# T3D-W055 — `bmp-embedded-codec-unsupported`

<!-- Generated from packages/asset-compiler-rust/messages.json by scripts/message-pages.ts: edit the catalogue, then run `pnpm run generate:messages`. -->

Level: **warning**. Group: [Images](../COMPILER_ERRORS.md#images).

A BMP wrapping a JPEG or PNG was refused, so the texture falls back to white.

**Cause.** `BI_JPEG` or `BI_PNG`: another format wrapped, which has its own plugin; unwrapping it here would bypass the router

**What to do.** Save the texture as a plain JPEG or PNG file.
