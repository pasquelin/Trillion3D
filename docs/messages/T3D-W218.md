# T3D-W218 — `image-block-budget-exceeded`

<!-- Generated from packages/sdk-node/src/messages/messages.json by scripts/message-pages.ts: edit the catalogue, then run `pnpm run generate:messages`. -->

Level: **warning**. Group: [Images](../COMPILER_ERRORS.md#images).

A compressed texture exceeds the allocation budget for its GPU blocks.

**Cause.** The sum of the native mip block payloads exceeds the received allocation ceiling; extraction or transcoding is refused before allocation

**What to do.** Reduce the texture resolution or use the existing pixel fallback.
