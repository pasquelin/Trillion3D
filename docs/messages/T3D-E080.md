Level: **error**. Group: [Node adapter and CLI](../COMPILER_ERRORS.md#node-adapter-and-cli).

The compiler program is missing.

**Cause.** No file at the executable the Node adapter resolved: `options.executable`, `TRILLION3D_COMPILER_BIN`, or the installed package's compiler.

**What to do.** Reinstall `trillion3d`, or set `TRILLION3D_COMPILER_BIN` to the path of a compiler program.
