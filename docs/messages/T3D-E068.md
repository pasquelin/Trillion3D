Level: **error**. Group: [USD](../COMPILER_ERRORS.md#usd).

The USDZ package stores an entry compressed or unaligned.

**Cause.** A USDZ entry compressed, or its payload not on a 64-byte boundary; the AOUSD package layout requires every file stored as-is and aligned

**What to do.** Package the scene again with `usdzip` or a USD tool that writes the standard layout.
