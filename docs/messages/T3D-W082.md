# T3D-W082 — `ktx2-orientation-unsupported`

<!-- Generated from packages/sdk-node/src/messages/messages.json by scripts/message-pages.ts: edit the catalogue, then run `pnpm run generate:messages`. -->

Level: **warning**. Group: [Images](../COMPILER_ERRORS.md#images).

A KTX2 orientation the reader cannot map was kept as stored, so the texture may appear flipped.

**Cause.** A `KTXorientation` not reducible to the contract's (top row first, left to right): starting leftwards, or a third dimension. `rd` (the contract's) and `ru` (flipped vertically) are handled; otherwise texels stay as stored

**What to do.** Export the texture with the standard top-down, left-to-right orientation.
