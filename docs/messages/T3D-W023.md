# T3D-W023 — `texture-embedded-format`

<!-- Generated from packages/sdk-node/src/messages/messages.json by scripts/message-pages.ts: edit the catalogue, then run `pnpm run generate:messages`. -->

Level: **warning**. Group: [Lights and OBJ/MTL materials](../COMPILER_ERRORS.md#lights-and-objmtl-materials).

An embedded texture is in an image format the importer does not read, so it is dropped.

**Cause.** An FBX texture carried inside the file whose name gives no supported image format.

**What to do.** Embed the texture as PNG or JPEG, or place it beside the model.
