# T3D-I014 — `unity-emission-keyword-off`

Level: **info**. Group: [Unity](../COMPILER_ERRORS.md#unity).

A material stores an emission colour but does not enable emission, so it does not glow.

**Cause.** Keywords declared without `_EMISSION` beside a stored emissive colour: it does not emit

**What to do.** Enable Emission on the material if it should glow.
