# T3D-W076 — `ktx2-format-unsupported`

<!-- Generated from packages/asset-compiler-rust/messages.json by scripts/message-pages.ts: edit the catalogue, then run `pnpm run generate:messages`. -->

Level: **warning**. Group: [Images](../COMPILER_ERRORS.md#images).

A KTX2 pixel format outside the read list was refused, so the texture falls back to white.

**Cause.** A `vkFormat` outside the declared list (signed BC4/BC5/EAC, BC6H float, byte orders other than RGBA, channels wider than 8 bits, ASTC footprints other than 4x4)

**What to do.** Export the texture with an 8-bit RGBA, BC or 4x4 ASTC format.
