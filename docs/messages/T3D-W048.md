# T3D-W048 — `image-transfer-unsupported`

<!-- Generated from packages/sdk-node/src/messages/messages.json by scripts/message-pages.ts: edit the catalogue, then run `pnpm run generate:messages`. -->

Level: **warning**. Group: [Images](../COMPILER_ERRORS.md#images).

A texture declares an unsupported transfer curve.

**Cause.** An unsupported PNG gamma is reported and read as sRGB; an AVIF transfer other than sRGB is refused rather than reinterpreted.

**What to do.** Convert the texture to sRGB in an image editor.
