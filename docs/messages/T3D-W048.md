# T3D-W048 — `image-transfer-unsupported`

<!-- Generated from packages/asset-compiler-rust/messages.json by scripts/message-pages.ts: edit the catalogue, then run `pnpm run generate:messages`. -->

Level: **warning**. Group: [Images](../COMPILER_ERRORS.md#images).

A PNG gamma other than sRGB or linear was ignored; the texture is read as sRGB.

**Cause.** A PNG `gAMA` neither 45455 (sRGB) nor 100000 (linear), with no `iCCP` or `sRGB` chunk overriding it; treated as sRGB, the convention for a silent file

**What to do.** Convert the texture to sRGB in an image editor.
