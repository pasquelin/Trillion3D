# T3D-W059 — `dds-codec-unsupported`

<!-- Generated from packages/sdk-node/src/messages/messages.json by scripts/message-pages.ts: edit the catalogue, then run `pnpm run generate:messages`. -->

Level: **warning**. Group: [Images](../COMPILER_ERRORS.md#images).

A DDS codec outside the read list was refused, so the texture falls back to white.

**Cause.** A codec outside the declared list (BC6H float, signed variants, `_TYPELESS`, 16-bit, YUV, premultiplied-alpha `DXT2`/`DXT4`)

**What to do.** Export the texture as BC1 to BC7 (8-bit), or as PNG.
