# T3D-W089 — `psd-alpha-channel-ignored`

<!-- Generated from packages/asset-compiler-rust/messages.json by scripts/message-pages.ts: edit the catalogue, then run `pnpm run generate:messages`. -->

Level: **warning**. Group: [Images](../COMPILER_ERRORS.md#images).

An extra Photoshop channel not declared as transparency was ignored.

**Cause.** One extra plane not declared transparency — the signed layer count Adobe's specification uses to say "the first alpha channel of the composite holds the document transparency" is absent or positive: a saved selection, read and written nowhere (taking it for transparency punched holes in the texture)

**What to do.** Store transparency as a layer mask flattened into the composite, or export the texture as PNG.
