# T3D-W115 — `usd-subdivision-unsupported`

Level: **warning**. Group: [USD](../COMPILER_ERRORS.md#usd).

A subdivision surface was carried as its flat polygons, which changes its silhouette.

**Cause.** A `Mesh` whose `subdivisionScheme` is not `none`: polygons carried **flat**, changing the silhouette

**What to do.** Subdivide the mesh in the authoring tool before exporting, or set its scheme to `none`.
