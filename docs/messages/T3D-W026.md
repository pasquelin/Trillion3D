# T3D-W026 — `texture-outside-source`

<!-- Generated from packages/asset-compiler-rust/messages.json by scripts/message-pages.ts: edit the catalogue, then run `pnpm run generate:messages`. -->

Level: **warning**. Group: [Lights and OBJ/MTL materials](../COMPILER_ERRORS.md#lights-and-objmtl-materials).

A texture file lies outside the model's folder, so it is not copied.

**Cause.** A referenced texture path leaving the source folder.

**What to do.** Move the texture into the model's folder and point the material at it.
