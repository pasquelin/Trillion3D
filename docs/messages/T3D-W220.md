# T3D-W220 — `image-transform-unsupported`

<!-- Generated from packages/sdk-node/src/messages/messages.json by scripts/message-pages.ts: edit the catalogue, then run `pnpm run generate:messages`. -->

Level: **warning**. Group: [Images](../COMPILER_ERRORS.md#images).

The AVIF declares a crop, rotation or mirror that this decoder cannot apply.

**Cause.** A container transform would require pixel reordering or cropping that the source decoder does not implement.

**What to do.** Apply the transform to the pixels in an image editor, then export without a container transform.
