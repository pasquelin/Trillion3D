# T3D-W050 — `image-depth-unsupported`

<!-- Generated from packages/sdk-node/src/messages/messages.json by scripts/message-pages.ts: edit the catalogue, then run `pnpm run generate:messages`. -->

Level: **warning**. Group: [Images](../COMPILER_ERRORS.md#images).

A texture with more than 8 bits per channel was refused, so it falls back to white.

**Cause.** The source depth exceeds the eight-bit surface contract, including PNG, TIFF, DDS and AVIF; it is refused rather than silently narrowed.

**What to do.** Save the texture at 8 bits per channel.
