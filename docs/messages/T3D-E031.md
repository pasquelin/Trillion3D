# T3D-E031 — `UNSUPPORTED_COMPONENT`

Level: **error**. Group: [Global](../COMPILER_ERRORS.md#global).

A glTF accessor has a component type the compiler does not read.

**Cause.** An accessor `componentType` outside the glTF list, or not allowed for the attribute that reads it.

**What to do.** Export the model again with float, normalised integer or unsigned integer components.
