# T3D-W086 — `psd-depth-unsupported`

Level: **warning**. Group: [Images](../COMPILER_ERRORS.md#images).

A Photoshop file at 1, 16 or 32 bits per channel was refused, so the texture falls back to white.

**Cause.** 1, 16 or 32 bits per channel, which `Rgba8` cannot hold; refused before decoding rather than narrowed

**What to do.** Convert the document to 8 bits per channel.
