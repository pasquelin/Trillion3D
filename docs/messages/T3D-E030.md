A glTF accessor has a missing or unknown type.

**Cause.** An accessor `type` absent, or outside the ones glTF defines for the attribute that reads it.

**What to do.** Export the model again with standard accessor types (`SCALAR`, `VEC2`, `VEC3`, `VEC4`, `MAT4`).
