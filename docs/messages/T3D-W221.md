# T3D-W221 — `image-primaries-unsupported`

<!-- Generated from packages/sdk-node/src/messages/messages.json by scripts/message-pages.ts: edit the catalogue, then run `pnpm run generate:messages`. -->

Level: **warning**. Group: [Images](../COMPILER_ERRORS.md#images).

The AVIF colour primaries are not supported by the decoder.

**Cause.** The source decoder accepts BT.709/sRGB primaries and does not convert other or unspecified primaries.

**What to do.** Convert the image to sRGB in an image editor before exporting it again.
