# T3D-W185 — `unity-material-clip-and-blend`

<!-- Generated from packages/sdk-node/src/messages/messages.json by scripts/message-pages.ts: edit the catalogue, then run `pnpm run generate:messages`. -->

Level: **warning**. Group: [Unity](../COMPILER_ERRORS.md#unity).

A material declares both transparency and alpha clipping; transparency wins and the clip threshold is lost.

**Cause.** Transparency **and** alpha clipping declared (`_Mode`, `_Surface`, `_AlphaClip`/`_AlphaCutoffEnable`): `BLEND` wins, since `MASK` would make pixels fully opaque or drop them; the threshold is lost, glTF reading `alphaCutoff` only under `MASK`

**What to do.** Choose either transparent or alpha-clipped rendering for the material.
