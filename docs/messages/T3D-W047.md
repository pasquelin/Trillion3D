# T3D-W047 — `image-icc-profile-ignored`

<!-- Generated from packages/sdk-node/src/messages/messages.json by scripts/message-pages.ts: edit the catalogue, then run `pnpm run generate:messages`. -->

Level: **warning**. Group: [Images](../COMPILER_ERRORS.md#images).

An embedded colour profile was ignored; the texture is read as sRGB.

**Cause.** An embedded colour profile — PNG `iCCP`, JPEG `ICC_PROFILE` APP2 segment, Photoshop image resource 1039 — that the sRGB output, with no colour management, does not carry; a profile naming itself sRGB counts nothing

**What to do.** Convert the texture to sRGB in an image editor.
