# T3D-W049 — `image-profile-unsupported`

<!-- Generated from packages/sdk-node/src/messages/messages.json by scripts/message-pages.ts: edit the catalogue, then run `pnpm run generate:messages`. -->

Level: **warning**. Group: [Images](../COMPILER_ERRORS.md#images).

A texture profile or codec was declined.

**Cause.** The TIFF profile or codec is unsupported, or an AVIF carries an ICC profile that the decoder cannot convert.

**What to do.** Convert the texture to sRGB in an image editor and export as PNG, or use a supported source profile.
