# T3D-W019 — `material-split-metal-roughness`

<!-- Generated from packages/sdk-node/src/messages/messages.json by scripts/message-pages.ts: edit the catalogue, then run `pnpm run generate:messages`. -->

Level: **warning**. Group: [Lights and OBJ/MTL materials](../COMPILER_ERRORS.md#lights-and-objmtl-materials).

Metalness and roughness come from different maps, which glTF cannot carry.

**Cause.** An FBX or OBJ material whose metalness and roughness maps are two files; neither is bound.

**What to do.** Pack metalness and roughness into one texture (blue and green channels).
