# The engine

A session draws with one engine, the WebGPU page raster, reading `source.gltf`: its renderer is a family
loaded beside the scene (`webgpuEngine`, `engine/factory.ts`). A bench page hands the session the
raster's factory itself (`engine`, a measurement seam no host reaches) and skips that load.

A machine with no WebGPU device is refused by name, `WEBGPU_UNAVAILABLE`, on the session's `fatal`
event, before anything is read for the scene. The witnesses the bench compares against draw in pages of
their own ([bench/runner/README.md](../../bench/runner/README.md)); the session never mounts one.
