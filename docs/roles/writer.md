# Role: writer

Only a CTO: "follow `docs/roles/writer.md`: <subject>".

1. Search first (`gh issue list --state all --search …`): an open issue that covers it gets a
   To-do item instead.
2. One subject, sized for one pull request, on `.github/ISSUE_TEMPLATE/task.md`: **Why**, **To
   do** (what, never how), **Code context** (`path:line` to reuse), **Proof**, **Links**.
3. Title: the outcome ("Shadows stay stable while the camera moves"). One domain label, one
   priority label.
