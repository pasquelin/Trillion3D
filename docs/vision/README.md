Ce dossier archive les documents de transfert qui décrivent un moteur de géométrie virtualisée (QEM, VGE1, imposteurs, pipeline GPU avancé). **Aucun de ces symboles n’est exporté par `@web-geometry/sdk`.**

Le contrat actuel est [Format 1](../FORMAT.md) et [packages/README.md](../../packages/README.md).
